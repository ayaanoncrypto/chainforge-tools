# ChainForge Tools: Visual Direction

## Three possible approaches

### Approach 1
**Theme Name:** Protocol Ledger

**Very Brief Intro:** A dark editorial operating system for crypto utilities. It uses dense but calm information hierarchy and physical-material detail instead of a neon trading aesthetic.

**Probability:** 0.07

### Approach 2
**Theme Name:** Quarry Terminal

**Very Brief Intro:** A utilitarian industrial workspace with raw grids, steel tones, and hard data marks. It feels like software for builders working close to infrastructure.

**Probability:** 0.03

### Approach 3
**Theme Name:** Orbit Index

**Very Brief Intro:** A light archival index with technical blue type, paper-like fields, and orbital relationship marks. It turns a tool catalog into a research library.

**Probability:** 0.08

## Chosen direction: Protocol Ledger

### Design Movement
Contemporary editorial systems design combined with precision industrial product design. The interface should resemble a well-designed financial journal that has become an operating environment, not a generic crypto dashboard.

### Core Principles
1. Treat the tool directory as an index, using strong category labels, sequence numbers, and precise metadata.
2. Use contrast through density and scale, with expressive display typography above compact functional controls.
3. Show technical depth with hairline rules, micro labels, discreet status lights, and diagram-like spatial rhythm.
4. Keep visual effects restrained. Substance and interaction should lead the experience.

### Color Philosophy
Obsidian carries focus and protects long work sessions. Slate and graphite establish layers without flat black emptiness. Cobalt signals analysis, active controls, and connected routes. Acid lime is reserved for one high-value state: an action completed, a live tool, or a confirmed calculation. The core signature color is **Forge Lime, #B8FF3D**.

### Layout Paradigm
Use a split-index workspace, not a centered marketing page. The persistent left rail holds categories and navigation. The center pane holds an oversized editorial introduction, search, and structured tool index. The right pane holds a rotating "tool bench" preview and data markers. On smaller screens, the layout collapses into a focused single-column index with category chips.

### Signature Elements
1. A slanted chain-link glyph inside square coordinate brackets.
2. Horizontal indexed rules with numeric section markers, similar to a field manual.
3. Small acid-lime signal dots used only for live, copied, calculated, or featured states.

### Interaction Philosophy
Interactions should feel like a reliable workbench. Search updates immediately. Selecting a tool opens a focused workspace without navigating away. Calculators update on input. Copy and run actions give brief, clear confirmation. Hover treatment should be tactile and restrained.

### Animation
Use 160 to 240 millisecond transform and opacity transitions with crisp ease-out timing. Tool rows lift two pixels on hover and reveal the action arrow. The selected tool bench should fade and slide in from the right at 0.95 scale. Accent signal dots can pulse once on completed calculations. Respect reduced motion settings.

### Typography System
Use **DM Mono** for tool labels, input values, metadata, and status language. Use **Manrope** for body copy and controls. Use **Space Grotesk** for display hierarchy, with bold compressed-feeling line breaks. The largest heading should use Space Grotesk at heavy weight with tight tracking. Never use Inter.

### Brand Essence
ChainForge is a high-utility crypto workbench for operators, developers, analysts, and self-directed users who want fast private tools without a cluttered dashboard.

**Personality:** Exact, composed, industrial.

### Brand Voice
Headlines should speak in direct operational language. CTAs should name the action. Microcopy should describe the output or condition in plain technical terms.

Example headline: "Utilities for the on-chain work in front of you."

Example CTA: "Open gas estimator"

### Wordmark and Logo
The mark is an offset chain-link form with a strong diagonal slash and no inherent coin imagery. The wordmark uses a compact geometric treatment where the F crossbar subtly repeats the logo diagonal. The website header uses the standalone mark at a visible 36-pixel scale.

### Signature Brand Color
Forge Lime, **#B8FF3D**.

## Style Decisions

- Hero and preview imagery use cobalt chain-link schematics, ledger artifacts, or material tool surfaces. They never use generic glowing blockchain-network scenes.
- The slanted chain-link bracket mark appears in the logo system, indexed dividers, and tool-bench framing as the recurring ChainForge motif.
- Long catalog views use numbered editorial rule headers by category so the directory reads like a field manual.
- The right bench rail carries persistent category telemetry and a low-contrast bracket schematic across long catalog views. It never reads as an empty decorative gutter.
- The wordmark uses a compact geometric ChainF/orge lockup with a visible diagonal slash through the F. This lockup remains distinct from small system labels.
